# ai-log

**Tri-Tetra Theory (TTT) の検証 — AIとの会話記録**

このリポジトリは、Tri-Tetra Theory (TTT) の検証を目的として、AIとの会話を記録・保存するためのものです。
特に新規性・独自性のある議論や発見を中心に記述します。

## 目的

- TTT 理論に関してAIと交わした会話を時系列で記録する
- 会話の中から新規性のある考察・論点を抽出・整理する
- 理論の発展過程を後から参照できるようにする

## ディレクトリ構成

```
conversations/
  YYYY-MM-DD_テーマ.md   # 会話ログ（日付_テーマ名）
TEMPLATE.md              # 会話ログのテンプレート
```

## 記録フォーマット

各会話ログは `conversations/` フォルダに `YYYY-MM-DD_テーマ.md` の形式で保存します。
詳しくは [TEMPLATE.md](TEMPLATE.md) を参照してください。
